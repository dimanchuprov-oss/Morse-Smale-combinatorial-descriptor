# Методичка по математике morse-lidar

Готовый PDF: [methodichka.pdf](methodichka.pdf), 81 страница.

Темы:
- теория Морса и критические точки на триангуляциях (нижний и верхний линк, SoS);
- эйлерова характеристика;
- комплекс Морса–Смейла, сепаратрисы, двойственный трёхвалентный граф;
- персистентные гомологии и bottleneck;
- кривизна и скалярные поля;
- граничные эффекты;
- линейная алгебра для 3D.

В каждой главе есть раздел «В коде» со ссылками на `src/morse_lidar/` и вопросы для самопроверки. В главе 0 — карта конвейера и порядок чтения, в главе 11 — учебный маршрут, упражнения и литература.

Исходники — `chNN.md` (pandoc Markdown). Рисунки считает сама библиотека скриптами `figures/chNN_figures.py`, запускать из корня репозитория через `.venv/bin/python`. Пересборка PDF: `zsh docs/methodichka/build.sh`, нужны pandoc и Google Chrome.
